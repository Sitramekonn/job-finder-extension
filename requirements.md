# RoleGenie Requirements

RoleGenie is a PHP/MySQL job-search application that supports account creation, resume upload, job discovery, job-match review, and application support workflows.

## Functional areas
- User registration, login, logout, and account management
- PDF resume upload and parsing
- Job search through an external job-search API
- Job listing storage and match presentation
- Resume and cover-letter generation workflows
- Application activity tracking

## Local environment
- PHP
- MySQL
- Composer
- Web server capable of running PHP
- API credentials configured locally through environment variables

See README.md for setup guidance.
