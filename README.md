# RoleGenie – Job Finder Personal Extension

A PHP/MySQL job-search web application extended from an existing codebase as a personal software-development project. This edition focuses on adding and refining use cases and features, improving the user-facing experience, integrating changes into the existing application, troubleshooting issues, and completing final functional and end-to-end testing.

## My Work

- Added and refined application use cases and features.
- Enhanced the landing-page and user-interface experience.
- Modified and integrated functionality within the existing PHP application architecture.
- Troubleshot application behavior and validated key user workflows.
- Performed final functional and end-to-end testing of the completed application.

## Main Application Areas

The project includes user authentication, job-search workflows, resume-related functionality, application activity tracking, account management, and API-backed application features.

## Running Locally

1. Install PHP, MySQL, and Composer.
2. Configure the database using the schema in `SQL/`.
3. Copy `.env.example` to `.env` and add your own local credentials/API configuration.
4. Run `composer install`.
5. Serve the application using your preferred local PHP environment.

> Do not commit real API keys, passwords, or `.env` files.
